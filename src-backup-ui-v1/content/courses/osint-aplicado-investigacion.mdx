# OSINT Aplicado a la Investigación Institucional

Programa orientado al uso profesional de fuentes abiertas para apoyar procesos de investigación, análisis de información y generación de productos de inteligencia.

## Objetivo

Desarrollar capacidades para localizar, validar, relacionar y documentar información pública de forma estructurada, ética y reproducible.

## Dirigido a

- Fiscalías.
- Policías de investigación.
- Agencias de inteligencia.
- Instituciones navales.
- Unidades de análisis.
- Equipos de investigación patrimonial.
- Personal de seguridad y justicia.

## Temario

### Módulo 1. Fundamentos de OSINT

- Conceptos fundamentales.
- Ciclo de inteligencia.
- Fuentes abiertas.
- Planeación de una investigación.
- Definición de objetivos y requerimientos.

### Módulo 2. Investigación de personas

- Identificación de perfiles.
- Alias y nombres de usuario.
- Correlación de cuentas.
- Búsqueda avanzada.
- Validación de información.

### Módulo 3. Investigación de organizaciones

- Empresas y estructuras corporativas.
- Relaciones comerciales.
- Dominios e infraestructura digital.
- Personas relacionadas.
- Construcción de líneas de investigación.

### Módulo 4. Análisis de vínculos

- Personas.
- Empresas.
- Bienes.
- Ubicaciones.
- Eventos.
- Representación gráfica de relaciones.

### Módulo 5. Documentación y evidencia

- Registro de hallazgos.
- Preservación de fuentes.
- Capturas y referencias.
- Elaboración de informes.
- Limitaciones y consideraciones legales.

## Metodología

El curso combina explicación técnica, ejercicios prácticos, análisis de casos y elaboración de productos de investigación.

## Resultados esperados

Al finalizar, el participante podrá:

- Diseñar búsquedas estructuradas.
- Validar información proveniente de fuentes abiertas.
- Identificar relaciones relevantes.
- Organizar hallazgos.
- Elaborar informes técnicos.
- Reconocer riesgos y limitaciones metodológicas.

## Modalidad institucional

El contenido puede adaptarse al perfil operativo, experiencia y necesidades específicas de cada institución.
